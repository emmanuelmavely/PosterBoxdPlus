Unlock live Movie, TV Series & Logo fetching

Your credential is stored in this browser (localStorage) and sent directly to TMDB to authenticate requests. PosterBoxd has no app server.

Get a TMDB key in a few minutes
  1. Create a free TMDB account or sign in.
  2. Open your profile Settings → API, then choose Request an API Key → Developer.
  3. Accept the terms and copy the API Key (v3) or API Read Access Token into the field above.
